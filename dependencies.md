# Dependencies

Asimov depends on a number of Python packages to function. Here are the main ones:

- [pyvirtualcam](https://github.com/letmaik/pyvirtualcam) — Sends frames to a virtual camera.
- [opencv-python](https://pypi.org/project/opencv-python/) — Python bindings for OpenCV for computer vision tasks.
- [numpy](https://numpy.org/) — Fundamental package for scientific computing.
- [mediapipe](https://developers.google.com/mediapipe) — Cross-platform framework for building multimodal applied ML pipelines.
- [PyQt5](https://pypi.org/project/PyQt5/) — Python bindings for the Qt GUI framework.

Please make sure all dependencies are installed in your Python environment before running Asimov.
